# 月尽时（Moon Without Return）

<p align="center">
  <img src="./img/logo.png" alt="月尽时 Logo" width="520">
</p>

《月尽时》是一款以心理悬疑、场景探索、解谜和多结局叙事为核心的网页游戏。玩家将在月面基地与一段被重建的家庭记忆之间穿行，通过调查、对话和选择逐步接近事件真相。

## 游戏特色

- 剧情驱动的章节式探索体验
- 家庭记忆、现实基地、地下设施与档案重建等多个区域
- 对话选择、证据收集和任务推进系统
- 多种谜题与互动小游戏
- 多存档、成就、难度及按键设置
- 根据玩家选择生成不同结局
- 数据保存在浏览器本地，无需后端服务

## 本地运行

本项目使用原生 HTML、CSS 和 JavaScript 开发，不需要安装项目依赖。

### 方法一：直接打开

双击项目根目录下的 `index.html`，浏览器会自动进入游戏登录页面。

### 方法二：启动本地服务器（推荐）

在项目根目录打开终端并执行：

```bash
python -m http.server 8000
```

然后在浏览器访问：

```text
http://localhost:8000
```

若系统中使用的是 `python3`，请执行：

```bash
python3 -m http.server 8000
```

## 基本操作

| 按键 | 功能 |
| --- | --- |
| `W` `A` `S` `D` / 方向键 | 移动或控制谜题 |
| `Space` | 推进对话或确认操作 |
| `Enter` | 跳过当前对白或执行界面操作 |
| `Q` | 打开任务与证据界面 |
| `Tab` | 查看区域地图 |
| `Esc` | 暂停或关闭当前界面 |

部分操作可在游戏设置中调整，具体提示以游戏内界面为准。

## 项目结构

```text
moon_without_return/
├─ index.html          # 项目入口
├─ login/              # 登录与注册页面
├─ main/               # 游戏主菜单
├─ game/               # 剧情、地图、谜题及主要游戏逻辑
├─ save/               # 存档管理页面
├─ achievement/        # 成就与结局展示
├─ settings/           # 游戏设置页面
├─ about/              # 团队介绍页面
├─ shared/             # 公共样式、存储与通用逻辑
├─ img/                # 地图、角色、道具及界面素材
└─ output/             # 项目说明图与流程图
```

## 地图区域

游戏地图资源位于 `img/maps/`，主要分为：

- `F`：虚拟家庭区域
- `R`：现实基地
- `B`：地下层
- `A`：档案重建区域

区域连接信息记录在 `img/maps/maps_manifest.json` 中。

## 存档说明

账号信息、游戏设置、存档和已解锁成就主要保存在当前浏览器的本地存储中。清除浏览器网站数据、切换浏览器或使用隐私模式，可能导致存档无法继续使用。
